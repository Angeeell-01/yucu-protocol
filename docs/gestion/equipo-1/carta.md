Las partes dejan por escrito que:

- Esta colaboración **no tiene costo** para la organización ni para sus socias.
- **No garantiza ventas ni ingresos.**
- **No otorga certificaciones** de ningún tipo (ni de origen, ni de calidad, ni de comercio justo).
